# Task Manager

A small task manager built with HTML, CSS, and JavaScript. Tasks are stored in Supabase through its generated REST API and the static site is intended for GitHub Pages.

## Setup

1. Create a Supabase project for demonstration data and create the table below.
2. In `config.json`, set the project URL and public publishable key. Never put a service role key or database password in this file.
3. Enable Row Level Security and add policies permitting anonymous select, insert, update, and delete. Use test data only.
4. Publish the repository root from the `main` branch using GitHub Pages.

```sql
create table public.tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  description text,
  completed boolean not null default false
);

alter table public.tasks enable row level security;
create policy "Public demo task access" on public.tasks
  for all to anon using (true) with check (true);
```

This public policy is only suitable for the course demonstration. Do not store private or sensitive data in this database.
